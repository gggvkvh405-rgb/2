# ByAzen — тишина между словами

Тёмный минималистичный мессенджер: концепт бренда **и рабочее приложение** для телефона и ПК.

```
index.html      → редирект на приложение
app/            → само приложение (работает на телефоне и ПК)
concept.html    → презентация бренда: идея, айдентика, экраны, атмосфера
desktop/        → Electron-обёртка (Windows .exe, macOS, Linux)
tools/serve.js  → локальный сервер без зависимостей
BUILD.md        → как собрать .exe и .apk
```

## Что умеет приложение

- **Чаты и диалоги** — история по дням, группировка сообщений, статусы доставки/прочтения.
- **Настоящая отправка**: Enter или кнопка, автоответы собеседников с индикатором «печатает».
- **Фото** — выбор из галереи, сжатие на устройстве, полноэкранный просмотр.
- **Голосовые** — реальная запись с микрофона (MediaRecorder), длительность, волна, воспроизведение.
- **Реакции и ответы** — долгое нажатие / правый клик по сообщению, эмодзи, цитата-ответ, удаление, копирование.
- **Поиск** по чатам, людям и тексту сообщений.
- **Круги** — малые закрытые группы, создание своих.
- **Профиль** — имя, ник, статус, фото, акцентный цвет (Aurora / Mint / Violet / Amber).
- **Тихие часы** — расписание, в которое уведомления молчат.
- **Шифрование**: текст сообщений шифруется AES-256-GCM ключом устройства в localStorage.
- **Экспорт/импорт** резервной копии JSON, полное удаление данных.
- **PWA**: установка на домашний экран (Android/iOS), установка на ПК, офлайн-режим.
- **Адаптив**: на телефоне — нижняя навигация и полноэкранный диалог; на ПК — три колонки.

## Запуск

```bash
npm run serve
# приложение:  http://localhost:4173/app/index.html
# бренд-дек:   http://localhost:4173/concept.html
```

Телефон в той же Wi-Fi сети: `http://<IP-компьютера>:4173/app/index.html`

## Сборка .exe и .apk

```bash
npm install
npm run dist:win            # → release/ByAzen-Setup-1.0.0.exe (+ portable)
npx cap add android && npx cap sync android
npm run mobile:apk          # → android/app/build/outputs/apk/debug/app-debug.apk
```

Полная инструкция, включая GitHub Actions, — в [BUILD.md](BUILD.md).

## Важно про честность

В песочнице, где создавался проект, нет Android SDK и Windows-тулчейна, поэтому
готовые бинарники `.apk`/`.exe` здесь не собраны. Всё остальное готово: приложение
рабочее, конфиги сборки лежат в репозитории, сборка — одна команда на вашей машине
или в GitHub Actions (`.github/workflows/build.yml`).

## Концепт бренда

**Идея.** ByAzen читается как *By Azen* — «через тишину». Мессенджер проектировался
от обратного: сначала убрали всё лишнее, потом добавили необходимое.

**Принципы.** Меньше интерфейса — больше разговора · ночь как основное состояние ·
уважение к вниманию · приватность без настроек.

**Палитра.** Void `#060709`, Graphite `#10131A`, Azure `#2E7BFF`, Mint `#7CF2D4`,
Paper `#F3F5F7`, Fog `#8B929C`.

**Типографика.** Inter (600 / −4.5 % трекинга в заголовках) + JetBrains Mono для меток.

**Визуал.** `assets/` — кей-визуал, иконка, атмосферные фото и AI-рендеры интерфейса
для телефона и ПК.
